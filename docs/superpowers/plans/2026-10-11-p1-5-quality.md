## 背景（這份計畫要解決的事）

- 品質調查的三個根因：(1) trace 斷段被當成整筆失敗後盲切；(2) 各小段獨立吸附，切點兩側落在不同的路，補橋繞一大圈；(3) 繞路只有自行車偏好成本、開放筆畫不能反向。原型（`b436026`）推薦組合 C＋R035＋S＋V＋BR：overall 中位數 46→62、平均 48.4→54.4、length/target 中位數 2.01→1.69、ms 中位數 233→300、最大 521→1140。BR（嚴格接點＋裁切重試）已在最終修正做完。
- 最終修正之後的新問題：串接器固定從第 0 個部件往後接（ledger L64）。第 0 個部件的尾巴 route 不出去時，後面所有部件都被丟掉；committed baseline 裡 `star@taipei_daan@r30` 的 coverage 因此是 0（原本 66）。封閉筆畫斷成多條 chain 時也從不被當成圈。bench 的安全斷言失敗不一定讓 bench 以非 0 結束，`--force` 還能把它寫進 baseline。
- **已知風險（先寫在這裡，量測時對照）**：原型資料用現在的 compare（overall 與 coverage 都比，容忍 3）對 committed baseline 比，推薦組合會有 4 個 coverage 退步：`star@taipei_daan` 78→72、`letter_l@kaohsiung_lingya` 80→76、`square@taipei_daan@r30` 83→79、`hi@taipei_daan@r30` 84→79（主要來自 R035）。這些案例的 overall 都持平或上升。若檢查點 A 重現了這種退步，依 Task 8 的規則停下來回報，由使用者決定，不要自己調參數或改容忍值。

```python
def compare(results: list[CaseResult], baseline: dict[str, dict], tolerance: int = 3) -> list[str]:
    """回傳退步說明。

    安全斷言沒過（SAFETY_ERRORS）一律算，不看 baseline：新案例、baseline 原本就失敗的案例也算，
    否則一筆寫進 baseline 的 UnsafeRoute 之後就永遠不會再被抓到。
    其餘只比 baseline 有的案例：overall 或 coverage 比 baseline 低超過 tolerance，或從成功變失敗。
    只看 overall 會漏掉「cleanliness 上升抵掉 coverage 掉到 0」的退步（ledger L120）。
    """
    problems: list[str] = []
    for r in results:
        if r.error in SAFETY_ERRORS:
            problems.append(f"{r.name}：安全斷言沒過（{r.error}：{r.safety}）")
        elif r.name in baseline and (problem := _regression(r, baseline[r.name], tolerance)):
            problems.append(problem)
    return problems
```

```python
    """折線經過的 edge。edge_walk 整段配不上時（實測：吸附結果在死巷原地折返 A→B→A），從中間的點切成兩半各自配：

        edges = router.edges(points)
    except RoutingError:
        if len(points) <= 2:
            raise
        mid = len(points) // 2
        return _edges(router, points[: mid + 1]) + _edges(router, points[mid:])
    if not edges and len(set(points)) >= 2:
        raise RoutingError("沒有配到任何路段")
    return edges
```

```python
def adjacent(left: list[Segment], right: list[Segment]) -> bool:
    """left 的終點與 right 的起點相距 ≤ JOIN_TOLERANCE_M：可以直接串，不補 link。"""
    return haversine_m(left[-1].points[-1], right[0].points[0]) <= JOIN_TOLERANCE_M


def connect(
    router: MatchRouter,
    deadline: Deadline,
    left: list[Segment],
    right: list[Segment],
    kind: SegmentKind,
    stroke_index: int | None,
) -> list[Segment] | None:
    """把 right 接在 left 後面，回傳新的 list（不改動傳入的 list）。

    相鄰就直接串；否則用 join 補一段 kind 的 link（必要時裁 left 的尾巴、right 的開頭）。接不上回傳 None。
    吸附（補橋）、串接（connector）、封閉筆畫收尾都走這裡：接點規則只有這一份。
    """
    if adjacent(left, right):
        return [*left, *right]
    joined = join(router, deadline, left[-1], right[0], kind, stroke_index)
    if joined is None:
        return None
    return [*left[:-1], joined.before, joined.link, joined.after, *right[1:]]
```

```python
    """依序串成 chain（connect：相鄰直接串，否則補橋＋裁切重試）；接不上就斷開，斷開的部分交給串接器。

    None（繞不出來或被拒絕的繞路）一律斷開，不能改用橋接線補同一個缺口：
    否則被 MIN_LENGTH_RATIO 拒絕的塌縮、切角繞路會換個名字被收下（ledger L34）。
    """
    chains: list[list[Segment]] = [[]]
    for segment in pieces:
        if segment is None:
            chains.append([])
            continue
        joined = connect(ctx.router, ctx.deadline, chains[-1], [segment], "detour", ctx.stroke_index) if chains[-1] else [segment]
        if joined is None:
            chains.append([segment])
        else:
            chains[-1] = joined
    return [chain for chain in chains if chain]
```

```python
ANCHOR_TIE_M = 0.1  # 部件長度差不到這麼多視為一樣長（浮點誤差）


def _anchor(parts: list[Part]) -> int:
    """錨點：吸附後最長的部件，路線從它開始組裝，所以它一定不會被丟掉。
    一樣長的取索引小的：部件都一樣長時維持舊版以第 0 個部件為準。"""
    lengths = [sum(s.length_m for s in part.segments) for part in parts]
    longest = max(lengths)
    return next(i for i, length in enumerate(lengths) if longest - length < ANCHOR_TIE_M)


def _attach(
    router: MatchRouter, deadline: Deadline, route: list[Segment], body: list[Segment], at_end: bool
) -> list[Segment] | None:
    """body 接在 route 的尾端（at_end）或開頭；騎乘方向不變，接不上回傳 None。"""
    if at_end:
        return connect(router, deadline, route, body, "connector", None)
    return connect(router, deadline, body, route, "connector", None)


def _assemble(
    router: MatchRouter, deadline: Deadline, bodies: dict[int, list[Segment]], order: list[int], anchor: int
) -> Composition:
    """從錨點開始組裝：order 裡排在錨點後面的依序接在尾端，排在前面的由近到遠接在開頭。
    原定那一端接不上就試另一端，兩端都接不上才丟：一個出不去的端點只擋住接在它後面的那一次。"""
    k = order.index(anchor)
    route, dropped = bodies[anchor], []
    sides = [(i, True) for i in order[k + 1 :]] + [(i, False) for i in reversed(order[:k])]
    for i, at_end in sides:
        joined = _attach(router, deadline, route, bodies[i], at_end)
        if joined is None:
            joined = _attach(router, deadline, route, bodies[i], not at_end)
        if joined is None:
            dropped.append(i)
        else:
            route = joined
    return Composition(segments=route, dropped=sorted(dropped))
```

```python
def _stitch_closed(
    router: MatchRouter, deadline: Deadline, chains: list[list[Segment]]
) -> tuple[list[list[Segment]], bool]:
    """封閉筆畫：照筆畫順序把相鄰的 chain 接起來（connect：相鄰直接串，否則 connector＋裁切重試，與串接器同一套規則）。

    回傳 (chains, closed)。全部接上、而且最後一點與第一點相鄰 → 一條 chain、closed=True。
    收尾只接受相鄰、不另外補 route：只有一個部件時那段路沒有用，只會讓路線變長。
    中間有接不上的地方 → 從那裡斷開；最後一條與第一條相鄰就合成一條（最後一條在前），
    斷點只剩真正接不上的地方，不會在收尾處多出一個部件（star@taipei_daan@r30）。
    """
    runs = [chains[0]]
    for chain in chains[1:]:
        merged = connect(router, deadline, runs[-1], chain, "connector", None)
        if merged is None:
            runs.append(chain)
        else:
            runs[-1] = merged
    if len(runs) == 1:
        return runs, adjacent(runs[0], runs[0])
    if adjacent(runs[-1], runs[0]):
        return [runs[-1] + runs[0], *runs[1:-1]], False
    return runs, False
```

```python
class TwoRoadsRouter:
    """畫線夾在兩條平行的路中間：切點 MID 以西吸到北邊的路（LAT + SHIFT），以東吸到南邊的路（LAT - SHIFT）。

    其餘的點投影到該半邊的路上。route 走直線並計數。"""

    MID = 121.51
    SHIFT = 2 / 110_574
    ROADS = (LAT + SHIFT, LAT - SHIFT)

    def __init__(self) -> None:
        self.trace_inputs: list[list[tuple[float, float]]] = []
        self.trace_outputs: list[RouteResult] = []
        self.route_calls = 0

    def trace(self, points, *, search_radius_m):
        self.trace_inputs.append(list(points))
        lons = [lon for lon, _ in points]
        if min(lons) < self.MID - 1e-9 and max(lons) > self.MID + 1e-9:

        head = points[0] if on_road else (points[0][0], road)
        snapped = [head] + [(lon, road) for lon, _ in points[1:]]
        result = RouteResult(points=snapped, length_km=polyline_length_m(snapped) / 1000)
        self.trace_outputs.append(result)
        return result

    def route(self, start, end, *, shortest=False):
        self.route_calls += 1
        return RouteResult(points=[start, end], length_km=haversine_m(start, end) / 1000)
```

```python
def _solve(ctx: _Context, piece: list[LonLat]) -> list[Segment | _Failed]:
    """回傳依序排列的結果：trace 成功的 Segment，或切到最小仍失敗的 _Failed。這裡不呼叫 route。

    串接：左半 trace 成功時，右半的第一個點換成左半的實際終點（已經吸附在路上），
    兩半在切點自然接上，不必補橋（品質調查根因 2：兩半各自吸附，切點兩側常落在不同的路）。
    左半最後是失敗的小段時，右半照原本的輸入點開始。
    """
    ctx.deadline.check()
    try:
        return [segment_from("stroke", ctx.stroke_index, ctx.router.trace(piece, search_radius_m=ctx.search_radius_m))]
    except RoutingError:
        pass
    if len(piece) < 3 or polyline_length_m(piece) <= ctx.min_piece_m:
        return [_Failed(piece[0], piece[-1], polyline_length_m(piece))]
    mid = len(piece) // 2
    left = _solve(ctx, piece[: mid + 1])
    right = piece[mid:]
    if isinstance(left[-1], Segment):
        right = [left[-1].points[-1], *right[1:]]
    return left + _solve(ctx, right)
```

```python
FAILED = ("UnsafeRoute", "SafetyUndetermined", "AllStrokesFailed", "MatchTimeout")


def parse(path: str) -> dict[str, dict]:
    rows = {}
    for line in open(path, encoding="utf-8"):
        parts = line.split()
        if len(parts) >= 10 and "@" in parts[0] and parts[1].isdigit():
            rows[parts[0]] = {
                "overall": int(parts[1]), "coverage": int(parts[2]), "clean": int(parts[3]),

        f"{statistics.median(r['coverage'] for r in ok)} | {statistics.median(r['clean'] for r in ok)} | "
        f"{statistics.median(ratio):.2f} | {statistics.median(ms):.0f} / {max(ms)} | {uses} |"
```

```python
    if option.reverse:
        backwards = rematch(index)
        if backwards is not None:
            return backwards
    return part.segments

    if not parts:
        return Composition(segments=[], dropped=[])

    order = _two_opt(options, _greedy(options, deadline), deadline)
    _, chosen = _plan(options, order)
    bodies = {i: _body(parts[i], chosen[i], rematch, i) for i in order}
```

```python
def _rematcher(
```

**規則：** 兩段 Valhalla 結果接起來的地方，從接點往回沿路線走 8 m 得到 p、往前走 8 m 得到 q；p→接點→q 的轉角 > 30° 時，用 `route(p, q)`（shortest）檢查：路線的起訖要落在 p、q 的 1 m 內，長度不能比沿原路線經過接點的長度多 3 m 以上。不符合就是 Valhalla 不會直接騎過這個接點（轉向限制、立體交叉在平面上剛好是同一點……），視同沒接上：`join` 裁切重試，仍不行就斷開 chain／丟部件，絕不輸出。探針沿路線走、可以跨過很短的路段（避免一段零點幾公尺的 link 把轉彎藏起來）。兩個探針落在同一處（原地迴轉、沿同一條路折返）不檢查：route 量不出來；兩段都是 bicycle 合法結果，代表那條路雙向可騎（品質調查 §6：慢車迴轉推測合法，未查證）。整條可量的路線不到 1 m 時也不檢查。

```python
"""假 router：某個路口（blocked）不能轉彎，用來測接點轉彎檢查。

route：起點與終點都在 blocked 的 PROBE_RADIUS_M 內（也就是轉彎檢查的探針，接點前後各 8 m）時，
回傳往北繞一大圈（約 900 m）的路線，代表 Valhalla 不會直接騎過去；其他情況直接走直線。
trace：輸入點原樣回傳；blocked 是 piece 的中間點（不是頭尾）時失敗，所以在 blocked 轉彎的筆畫一定在那裡切開。
"""

from engine.routing.geo import haversine_m, polyline_length_m
from engine.routing.router import RouteResult, RoutingError

M_PER_DEG_LON = 100_900  # 緯度 25° 附近
M_PER_DEG_LAT = 110_574
PROBE_RADIUS_M = 10.0


def east(point, meters):
    return (point[0] + meters / M_PER_DEG_LON, point[1])


def north(point, meters):
    return (point[0], point[1] + meters / M_PER_DEG_LAT)


class TurnBlockRouter:
    def __init__(self, blocked=None) -> None:
        self.blocked = blocked
        self.route_calls: list[tuple] = []

    def _near(self, point) -> bool:
        return self.blocked is not None and haversine_m(point, self.blocked) <= PROBE_RADIUS_M

    def trace(self, points, *, search_radius_m):
        if self.blocked is not None and any(haversine_m(p, self.blocked) < 0.01 for p in points[1:-1]):
            raise RoutingError("跨過不能轉彎的路口")
        return RouteResult(points=list(points), length_km=polyline_length_m(points) / 1000)

    def route(self, start, end, *, shortest=False):
        self.route_calls.append((start, end))
        if self._near(start) and self._near(end):
            points = [start, north(start, 440), north(end, 440), end]
        else:
            points = [start, end]
        return RouteResult(points=points, length_km=polyline_length_m(points) / 1000)
```

`engine/src/engine/matching/turns.py`：

```python
"""接點轉彎檢查（品質調查 §5.3）：兩段 Valhalla 結果接起來的地方，Valhalla 自己會不會直接騎過去。

從接點沿路線往回走 TURN_PROBE_M 得到 p、往前走 TURN_PROBE_M 得到 q。p→接點→q 的轉角超過 TURN_CHECK_DEG 時，
route(p, q)（shortest）的起訖要落在 p、q 的 JOIN_TOLERANCE_M 內，長度不能比沿原路線經過接點多 TURN_SLACK_M 以上；
繞一大圈代表這個轉彎不能直接騎（轉向限制、立體交叉在平面上剛好是同一點……），接點視同沒接上。
兩個探針落在同一處（原地迴轉）沒辦法用 route 量，不檢查；可量的路線不到 JOIN_TOLERANCE_M 也不檢查。
"""

import math

from engine.matching.deadline import Deadline
from engine.matching.types import JOIN_TOLERANCE_M, MatchRouter, Segment, legal_route
from engine.routing.geo import haversine_m, polyline_length_m
from engine.routing.router import LonLat

TURN_CHECK_DEG = 30.0
TURN_PROBE_M = 8.0
TURN_SLACK_M = 3.0


def turn_deg(before: LonLat, at: LonLat, after: LonLat) -> float:
    """局部平面上 before→at 與 at→after 兩個方向的夾角：0 = 直行，180 = 原地迴轉。"""
    kx, ky = 111_320.0 * math.cos(math.radians(at[1])), 110_574.0
    ux, uy = (at[0] - before[0]) * kx, (at[1] - before[1]) * ky
    vx, vy = (after[0] - at[0]) * kx, (after[1] - at[1]) * ky
    nu, nv = math.hypot(ux, uy), math.hypot(vx, vy)
    if nu == 0 or nv == 0:
        return 0.0
    return math.degrees(math.acos(max(-1.0, min(1.0, (ux * vx + uy * vy) / (nu * nv)))))


def _walk(points: list[LonLat], meters: float) -> tuple[LonLat, float]:
    """從 points[0] 沿折線走 meters 公尺（不夠長就停在最後一點）；回傳 (到達的點, 實際走的距離)。"""
    walked = 0.0
    for a, b in zip(points, points[1:]):
        step = haversine_m(a, b)
        if step > 0 and walked + step >= meters:
            t = (meters - walked) / step
            return (a[0] + (b[0] - a[0]) * t, a[1] + (b[1] - a[1]) * t), meters
        walked += step
    return points[-1], walked


def tail_points(segments: list[Segment]) -> list[LonLat]:
    """路段串最後的 TURN_PROBE_M 公尺（不夠長就往前跨段）：rideable 的 incoming。"""
    out: list[LonLat] = []
    for segment in reversed(segments):
        out = segment.points + out
        if polyline_length_m(out) >= TURN_PROBE_M:
            break
    return out


def head_points(segments: list[Segment]) -> list[LonLat]:
    """路段串最前的 TURN_PROBE_M 公尺（不夠長就往後跨段）：rideable 的 outgoing。"""
    out: list[LonLat] = []
    for segment in segments:
        out = out + segment.points
        if polyline_length_m(out) >= TURN_PROBE_M:
            break
    return out


def rideable(router: MatchRouter, deadline: Deadline, incoming: list[LonLat], outgoing: list[LonLat]) -> bool:
    """incoming 的終點接 outgoing 的起點（相距 ≤ JOIN_TOLERANCE_M）時，Valhalla 會不會直接騎過這個接點。"""
    p, back_m = _walk(incoming[::-1], TURN_PROBE_M)
    q, ahead_m = _walk(outgoing, TURN_PROBE_M)
    if min(back_m, ahead_m) < JOIN_TOLERANCE_M or haversine_m(p, q) <= JOIN_TOLERANCE_M:
        return True
    if turn_deg(p, incoming[-1], q) <= TURN_CHECK_DEG:
        return True
    result = legal_route(router, deadline, p, q, JOIN_TOLERANCE_M)
    direct_m = back_m + haversine_m(incoming[-1], outgoing[0]) + ahead_m
    return result is not None and result.length_km * 1000 <= direct_m + TURN_SLACK_M
```

```python
def _attempt(
    router: MatchRouter,
    deadline: Deadline,
    before: Segment,
    after: Segment,
    tail: int,
    head: int,
    kind: SegmentKind,
    stroke_index: int | None,
) -> tuple[Joined | None, bool, bool]:
    """試一次：route 前段第 tail 點 → 後段第 head 點。回傳 (接上的結果或 None, 起點側沒接上, 終點側沒接上)。
    端點離要求的位置超過 JOIN_TOLERANCE_M，或接點的轉彎不能直接騎，都算那一側沒接上。"""
    start, end = before.points[tail], after.points[head]
    result = try_route(router, deadline, start, end)
    if result is None:
        return None, True, True
    start_missed = haversine_m(result.points[0], start) > JOIN_TOLERANCE_M
    end_missed = haversine_m(result.points[-1], end) > JOIN_TOLERANCE_M
    if start_missed or end_missed:
        return None, start_missed, end_missed
    kept_before, kept_after = _cut(before, before.points[: tail + 1]), _cut(after, after.points[head:])
    # 探針跨過 link：很短的 link 不能把前後兩段之間的轉彎藏起來
    start_missed = not rideable(router, deadline, kept_before.points, result.points + kept_after.points[1:])
    end_missed = not rideable(router, deadline, kept_before.points + result.points[1:], kept_after.points)
    if start_missed or end_missed:
        return None, start_missed, end_missed
    return Joined(kept_before, segment_from(kind, stroke_index, result), kept_after), False, False


def join(
    router: MatchRouter,
    deadline: Deadline,
    before: Segment,
    after: Segment,
    kind: SegmentKind,
    stroke_index: int | None,
) -> Joined | None:
    """接上 before 的終點與 after 的起點（兩端都已經在路上）；接不上回傳 None。"""
    last = len(before.points) - 1
    tails = [last] + [last - k for k in _marks(before.points[::-1])]  # 前段保留到第幾點
    heads = [0] + _marks(after.points)  # 後段從第幾點開始
    t = h = 0
    while True:
        joined, start_missed, end_missed = _attempt(router, deadline, before, after, tails[t], heads[h], kind, stroke_index)
        if joined is not None:
            return joined
        step = (min(t + start_missed, len(tails) - 1), min(h + end_missed, len(heads) - 1))
        if step == (t, h):  # 沒接上的那一端已經裁到底
            return None
        t, h = step
```
