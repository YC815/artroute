# P1-web：網站前端（圖形來源、地圖編輯器、即時吸附、GPX）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `web/` 建出 artroute 網站：英文字或圖片轉成筆畫，放到地圖上移動、旋轉、縮放，透過 `/api/match` 即時吸附成合法的自行車路線並下載 GPX；最後部署到 m1（維持 hl 預設鎖定）。

**Architecture:** Next.js App Router；整個工作室只在瀏覽器執行（`next/dynamic` 的 `ssr: false`）。所有純邏輯（投影、Hershey 解析與排版、Otsu、輪廓、Douglas-Peucker、GPX、節流排程、契約驗證）都是不依賴框架的 TypeScript 模組，用 vitest 測；React 元件只負責組裝。瀏覽器只呼叫同源的 `/api/match`、`/api/status`，Route Handler 用 zod 驗證後轉給內網的 `artroute-engine`，狀態碼原樣轉回。`/match` 的型別與 zod schema 集中在 `web/src/lib/engine/contract.ts`，之後改用 openapi-typescript 只需要改這個檔。

**Tech Stack:** Next.js 16.4.0（App Router、Turbopack、`output: "standalone"`）、React 19.3.0、TypeScript 5.9、Tailwind CSS 4、shadcn/ui 4.21.4（Radix 版）、MapLibre GL JS 6.13.0＋OpenFreeMap、hersheytext 2.0.0、d3-contour 4.0.2、zod 4.6.5、vitest 5.0.3、Playwright 1.64.0、pnpm 11.24.0、Node 24（Docker `node:24-alpine`）。

**對應設計文件：** `docs/superpowers/specs/2026-10-10-strava-art-design.md` 的 §1、§3、§4.1、§4.2、§4.7、§5、§6.2、§7 P1。

**不在本計畫範圍：** 引擎的 `/match` 實作（引擎計畫）、改用 openapi-typescript 產生型別（之後的整合 task，只改 `contract.ts`）、自動搜尋（P2）、`hl public` 與 rate limiting（P3）。

## Global Constraints

- JS/TS 一律用 pnpm：`pnpm add`、`pnpm dlx`、`pnpm exec`。不用 npm、yarn、bun。
- 版本（2026-10-11 以 `pnpm view` 確認）：`create-next-app@16.4.0`（產生 next 16.4.0、react／react-dom 19.3.0、typescript ^5、eslint ^9、tailwindcss ^4）、`shadcn@4.21.4`、`maplibre-gl@6.13.0`、`hersheytext@2.0.0`、`d3-contour@4.0.2`、`zod@4.6.5`、`vitest@5.0.3`、`@playwright/test@1.64.0`、`@types/d3-contour@3.0.6`、`@types/geojson@7946.0.16`、`@types/node@24.19.1`。
- 只有 Task 1 可以改 `web/package.json`、`web/pnpm-lock.yaml`、`web/pnpm-workspace.yaml`。後面的 task 需要新依賴時停下來回報，不要自己加（平行 worktree 才不會衝突）。
- UI 用 shadcn/ui（Radix 版）。`web/src/components/ui/` 是 shadcn 產生的檔案，不手改。
- 驗證只用會結束的指令：`pnpm test`、`pnpm exec tsc --noEmit`、`pnpm lint`、`pnpm build`、`pnpm test:e2e`（Playwright 自己啟動並關閉 server）。不在前景跑 `pnpm dev`、`pnpm start`、`--watch`。
- 程式碼註解、使用者看得到的字串一律繁體中文；識別字英文。唯一例外：Hershey 字型授權要求原文照錄的英文致謝。
- 文字來源：英文字母、數字、`♥ ! ? & . -` 與空白；最多 2 行、每行最多 10 字（空白也算），所以總數最多 20 字。字型 Hershey Sans（`futural`）與 Script（`scripts`）。每個字的每一筆各自是一個 `Stroke`，前端**不做任何連接**。
- 圖片來源：PNG、JPG、WebP，最大 5 MB。流程：灰階 → Otsu（滑桿可調）→ `d3-contour` → Douglas-Peucker。**不用 potrace（GPL-2.0）。**
- `/match` 請求上限（spec §4.7）：1–40 筆、每筆 2–2000 點、`search_radius_m` 30–150。
- 瀏覽器不直接連引擎，只透過 `/api/match`、`/api/status`。
- 絕不畫直線補線：地圖只畫引擎回傳的 `segments`；GPX 只輸出 `route.points`。
- 即時吸附：拖曳中每 300 ms 最多送一次、放開立刻送；新請求用 `AbortController` 取消舊請求；遞增序號保證舊結果不會覆蓋新結果。
- 引擎回 503 或連不上：顯示橫幅、停用吸附，可以重試。
- 程式風格：超過 3 層縮排就拆函式；分派用查表（`Record`、`Map`），不要堆 `if`／`switch`；資料來自任意字串（例如鍵盤按鍵）的查表用 `Map`，避免撞到 `constructor` 等原型屬性。
- 契約型別與 schema 一律從 `@/lib/engine/contract` import。
- 部署維持 hl 預設鎖定，**不得執行 `hl public`**。

## 已驗證與未驗證

- **已驗證**（2026-10-11，在暫存目錄照本計畫實際跑過）：Task 1 的 scaffold 指令與旗標、上面的版本組合、本計畫全部程式碼。`pnpm test`（18 個測試檔、116 個測試）、`pnpm exec tsc --noEmit`、`pnpm lint`、`pnpm build` 全部通過；`pnpm exec playwright test --list` 能列出 e2e。
- **已查證的第三方行為**：
  - `hersheytext` 的 JSON 是 `{字型鍵: {name, chars: [{d, o}]}}`，`chars[字元碼 − 33]`（從 `!` 開始、沒有空白），`d` 只用絕對座標 `M`／`L`（`L` 後可接多組座標），`o` 是半個字寬（推進寬度 = `2 × o`），座標 y 向下、大寫字高約 y 1–22。套件的 main 依賴 `cheerio` 與 `fs`，所以只 import `hersheytext/hersheytext.min.json`。字型裡沒有 `♥`。
  - `d3-contour`：`contours().size([w, h]).contour(values, threshold)` 回傳一個 MultiPolygon；每個 polygon 第一個環是外框、其餘是洞；環首尾相同；座標範圍 `[0, w] × [0, h]`。
  - MapLibre 6 是純 ESM，worker 是獨立檔案 `dist/maplibre-gl-worker.mjs`（自足、不 import 其他檔），預設用 `import.meta.url` 推算位置——打包後推不到，所以複製到 `public/` 並呼叫 `setWorkerUrl`。
  - Next 16.4 的 scaffold 預設開 `cacheComponents`；GET Route Handler 可能在 build 時預先產生，所以 `/api/status` 先 `await connection()`（build 輸出顯示 `ƒ /api/status`）。
  - eslint-config-next 16.4 內含 React Compiler 規則（`react-hooks/refs`、`react-hooks/set-state-in-effect`）：render 中不能讀寫 `ref.current`、effect 裡不能直接 `setState`。本計畫的元件已照這些規則寫。
  - `next start` 遇到 `output: "standalone"` 只印警告、照樣能跑（e2e 用它）。
  - Next 提供 `public/*.mjs` 的 Content-Type 是 `application/javascript`，module worker 可以載入。
- **未驗證、留在 task 裡當驗證步驟**：Playwright e2e 實際執行（無頭 Chromium 的 WebGL，Task 11）、Docker build 與 m1 部署（Task 12）、真引擎 `/match` 回應與 spec §4.7 一致（Task 12）。引擎的錯誤 body 格式 spec 沒規定，前端只假設 FastAPI 慣例的 `{detail}`，另外接受可省略的 `warnings`（Task 5）。

## 與 spec 的落差（照本計畫實作，完成後回報）

- 20 字的文字可能超過 `/match` 的 40 筆上限（例如 futural 的 `M`、`E`、`W` 一字 4 筆，20 個 `M` 是 80 筆）。spec 不允許前端連接筆畫，所以送出前檢查筆數，超過就顯示「筆畫有 N 筆，超過上限 40 筆」、不送出（Task 6 的 `shapeProblem`）。一般文字（例如 `HELLO WORLD` 24 筆、`I LOVE TAIPEI` 23 筆）不受影響。
- `♥` 不在 Hershey 的 ASCII 字表裡：用心形參數式產生一個封閉筆畫（Task 3）。

```ts
/** 公尺 → 「1.23 km」；不到 1 km 顯示「850 m」。 */
export function formatDistance(meters: number): string {
  if (meters < 1000) return `${Math.round(meters)} m`;
  return `${(meters / 1000).toFixed(2)} km`;
}

/** 路網版本（build id，例如 20261010T145928Z）→「2026-10-10」；格式不符就原樣回傳。 */
export function formatDataVersion(buildId: string): string {
  const match = /^(\d{4})(\d{2})(\d{2})T/.exec(buildId);
  return match ? `${match[1]}-${match[2]}-${match[3]}` : buildId;
}
```

```ts
import type { LonLat } from "@/lib/shape/types";

/** 地球平均半徑（公尺）。 */
const EARTH_RADIUS_M = 6_371_008.8;
const RAD = Math.PI / 180;

/**
 * 以 origin 為中心的局部切平面（等距圓柱，緯度取 origin 的緯度）。
 * 在作品尺度（≤ 20 km）內誤差可忽略，跟引擎評分用的局部平面一致。
 */
export function fromLocal(origin: LonLat, east: number, north: number): LonLat {
  const metersPerRadLon = EARTH_RADIUS_M * Math.cos(origin[1] * RAD);
  return [origin[0] + east / metersPerRadLon / RAD, origin[1] + north / EARTH_RADIUS_M / RAD];
}

/** fromLocal 的反函數：經緯度 → 相對 origin 的 [東, 北]（公尺）。 */
export function toLocal(origin: LonLat, p: LonLat): [number, number] {
  const metersPerRadLon = EARTH_RADIUS_M * Math.cos(origin[1] * RAD);
  return [(p[0] - origin[0]) * RAD * metersPerRadLon, (p[1] - origin[1]) * RAD * EARTH_RADIUS_M];
}
```

```ts
import type { Point, Stroke } from "@/lib/shape/types";

type Box = { minX: number; maxX: number; minY: number; maxY: number };

// 用迴圈而不是 Math.min(...xs)：圖片輪廓可能有上萬個點，展開參數會爆堆疊
function boundingBox(points: Point[]): Box {
  const box = { minX: Infinity, maxX: -Infinity, minY: Infinity, maxY: -Infinity };
  for (const [x, y] of points) {
    box.minX = Math.min(box.minX, x);
    box.maxX = Math.max(box.maxX, x);
    box.minY = Math.min(box.minY, y);
    box.maxY = Math.max(box.maxY, y);
  }
  return box;
}

/**
 * 來源座標（y 向下）→ 正規化座標（y 向上）：外框中心移到原點，長邊縮放成 1。
 * 文字和圖片共用這一個函式。
 */
export function normalizeStrokes(strokes: Stroke[]): Stroke[] {
  const points = strokes.flatMap((s) => s.points);
  if (points.length === 0) return [];
  const box = boundingBox(points);
  const scale = Math.max(box.maxX - box.minX, box.maxY - box.minY) || 1;
  const cx = (box.minX + box.maxX) / 2;
  const cy = (box.minY + box.maxY) / 2;
  return strokes.map((s) => ({
    closed: s.closed,
    points: s.points.map(([x, y]): Point => [(x - cx) / scale, (cy - y) / scale]),
  }));
}

/** 正規化圖形外框的半寬、半高（外框以原點為中心）。 */
export type ShapeBounds = { halfWidth: number; halfHeight: number };

export function shapeBounds(strokes: Stroke[]): ShapeBounds {
  const box = boundingBox(strokes.flatMap((s) => s.points));
  return {
    halfWidth: Math.max(0, Math.abs(box.minX), Math.abs(box.maxX)),
    halfHeight: Math.max(0, Math.abs(box.minY), Math.abs(box.maxY)),
  };
}
```

```ts
import { fromLocal, toLocal } from "@/lib/geo/local-plane";
import type { ShapeBounds } from "@/lib/shape/normalize";
import type { LonLat, Point, Stroke } from "@/lib/shape/types";

/**
 * 圖形在地圖上的擺放。
 * sizeM：正規化座標 1 單位對應的公尺數（= 外框長邊的公尺數）。
 * rotationDeg：順時針角度，0 = 圖形的上方朝北。
 */
export type Transform = { center: LonLat; sizeM: number; rotationDeg: number };

export const MIN_SIZE_M = 200;
export const MAX_SIZE_M = 20_000;
/** 旋轉把手在圖形上緣再往外多遠（正規化單位）。 */
export const ROTATE_HANDLE_GAP = 0.12;

const RAD = Math.PI / 180;

/** 正規化座標 → 經緯度。 */
export function transformPoint([x, y]: Point, t: Transform): LonLat {
  const cos = Math.cos(t.rotationDeg * RAD);
  const sin = Math.sin(t.rotationDeg * RAD);
  const east = t.sizeM * (x * cos + y * sin);
  const north = t.sizeM * (-x * sin + y * cos);
  return fromLocal(t.center, east, north);
}

export function transformStrokes(strokes: Stroke[], t: Transform): { points: LonLat[]; closed: boolean }[] {
  return strokes.map((s) => ({ points: s.points.map((p) => transformPoint(p, t)), closed: s.closed }));
}

/** 目標圖形的總長（公尺），封閉筆畫含收尾那一段。旋轉不影響長度。 */
export function shapeLengthM(strokes: Stroke[], sizeM: number): number {
  let total = 0;
  for (const s of strokes) {
    const pts = s.closed ? [...s.points, s.points[0]] : s.points;
    for (let i = 1; i < pts.length; i++) {
      total += Math.hypot(pts[i][0] - pts[i - 1][0], pts[i][1] - pts[i - 1][1]);
    }
  }
  return total * sizeM;
}

/** 四個角落把手與旋轉把手的經緯度。角落順序：右上、左上、左下、右下（圖形座標）。 */
export function handlePositions(t: Transform, b: ShapeBounds): { corners: LonLat[]; rotate: LonLat } {
  const corners: Point[] = [
    [b.halfWidth, b.halfHeight],
    [-b.halfWidth, b.halfHeight],
    [-b.halfWidth, -b.halfHeight],
    [b.halfWidth, -b.halfHeight],
  ];
  return {
    corners: corners.map((p) => transformPoint(p, t)),
    rotate: transformPoint([0, b.halfHeight + ROTATE_HANDLE_GAP], t),
  };
}

/** 拖曳本體：圖形跟著指標平移。 */
export function moveBy(t: Transform, from: LonLat, to: LonLat): Transform {
  return { ...t, center: [t.center[0] + to[0] - from[0], t.center[1] + to[1] - from[1]] };
}

/** 拉角落把手：等比縮放，讓角落落在指標到中心的距離上。 */
export function scaleTo(t: Transform, b: ShapeBounds, pointer: LonLat): Transform {
  const [east, north] = toLocal(t.center, pointer);
  const cornerDistance = Math.hypot(b.halfWidth, b.halfHeight) || 1;
  const sizeM = Math.hypot(east, north) / cornerDistance;
  return { ...t, sizeM: Math.min(MAX_SIZE_M, Math.max(MIN_SIZE_M, sizeM)) };
}

/** 拉旋轉把手：圖形的上方轉向指標。 */
export function rotateTo(t: Transform, pointer: LonLat): Transform {
  const [east, north] = toLocal(t.center, pointer);
  const deg = Math.atan2(east, north) / RAD;

/** 拖曳的種類：本體、角落把手、旋轉把手。 */

const DRAGS: Record<DragMode, (start: Transform, from: LonLat, to: LonLat, b: ShapeBounds) => Transform> = {
  move: (start, from, to) => moveBy(start, from, to),
  scale: (start, _from, to, b) => scaleTo(start, b, to),
  rotate: (start, _from, to) => rotateTo(start, to),
};

/** 拖曳中：從按下時的擺放 start、按下的位置 from，算出指標在 to 時的新擺放。 */
export function dragTransform(mode: DragMode, start: Transform, from: LonLat, to: LonLat, b: ShapeBounds): Transform {
  return DRAGS[mode](start, from, to, b);
}

// 用 Map 而不是物件：KeyboardEvent.key 可能是任意字串，物件會撞到 "constructor" 之類的原型屬性
const NUDGE = new Map<string, [number, number]>([
  ["ArrowUp", [0, 1]],
  ["ArrowDown", [0, -1]],
  ["ArrowLeft", [-1, 0]],
  ["ArrowRight", [1, 0]],
]);

  return NUDGE.has(key);
}

/** 方向鍵微調：每次 10 m，按住 Shift 100 m。不是方向鍵時回傳 null。 */
export function nudge(t: Transform, key: string, big: boolean): Transform | null {
  const dir = NUDGE.get(key);
  if (!dir) return null;
  const step = big ? 100 : 10;
  return { ...t, center: fromLocal(t.center, dir[0] * step, dir[1] * step) };
```

```ts
// Hershey 單筆畫字型。資料來自 hersheytext 套件的 JSON（字型資料為 Public Domain）。
// 只引入 JSON：套件的 main 依賴 cheerio 和 fs，不能在瀏覽器裡用。
import fontData from "hersheytext/hersheytext.min.json";
import type { Point, Stroke } from "@/lib/shape/types";

export const FONT_IDS = ["futural", "scripts"] as const;
export type HersheyFontId = (typeof FONT_IDS)[number];

export const FONT_LABELS: Record<HersheyFontId, string> = {
  futural: "Sans（Roman Simplex）",
  scripts: "Script（Script Simplex）",
};

/** 一個字：筆畫用來源座標（y 向下，大寫字高約 y 1–22），advance 是往右推進的寬度。 */
export type Glyph = { strokes: Stroke[]; advance: number };

// hersheytext JSON：chars[字元碼 - 33]，d 是只用 M/L 的 SVG 路徑，o 是半個字寬
type RawFont = { name: string; chars: { d: string; o: number }[] };
const FONTS = fontData as unknown as Record<HersheyFontId, RawFont>;
const FIRST_CHAR_CODE = 33;

/** 解析 Hershey 的 SVG 路徑（只有絕對座標 M、L；L 後面可以接多組座標）。每個 M 開始一筆。 */
export function parseHersheyPath(d: string): Point[][] {
  const strokes: Point[][] = [];
  for (const [, command, x, y] of d.matchAll(/([A-Za-z])|(-?\d+(?:\.\d+)?),(-?\d+(?:\.\d+)?)/g)) {
    if (command === "M") {
      strokes.push([]);
      continue;
    }
    if (command === "L") continue;
    if (command) throw new Error(`不支援的 SVG 路徑指令：${command}`);
    strokes[strokes.length - 1].push([Number(x), Number(y)]);
  }
  return strokes;
}

/** 首尾相同（至少 4 點）的筆畫視為封閉，去掉重複的終點。 */
export function toStroke(points: Point[]): Stroke {
  const first = points[0];
  const last = points[points.length - 1];
  const closed = points.length >= 4 && first[0] === last[0] && first[1] === last[1];
  return { points: closed ? points.slice(0, -1) : points, closed };
}

// ♥ 不在 Hershey 的 ASCII 範圍內：用經典心形參數式
// x = 16 sin³t，y = 13 cos t − 5 cos 2t − 2 cos 3t − cos 4t（y 範圍 −17 到 11.92），
// 縮放到 Hershey 大寫字高（y 1–22），寬 24。
const HEART_SAMPLES = 32;
const HEART_TOP = 11.92;
const HEART_SCALE = 21 / (HEART_TOP + 17);

function heartGlyph(): Glyph {
  const points: Point[] = [];
  for (let i = 0; i < HEART_SAMPLES; i++) {
    const t = (i / HEART_SAMPLES) * 2 * Math.PI;
    const x = 16 * Math.sin(t) ** 3;
    const y = 13 * Math.cos(t) - 5 * Math.cos(2 * t) - 2 * Math.cos(3 * t) - Math.cos(4 * t);
    points.push([12 + x * HEART_SCALE, 1 + (HEART_TOP - y) * HEART_SCALE]);
  }
  return { strokes: [{ points, closed: true }], advance: 24 };
}

/** hersheytext 資料沒有的字：空白（寬 16，約一個大寫字寬）和 ♥。兩套字型共用。 */
const EXTRA_GLYPHS: Record<string, Glyph> = {
  " ": { strokes: [], advance: 16 },
  "♥": heartGlyph(),
};

/** 取得一個字的筆畫；字型裡沒有的字回傳 null。 */
export function glyphFor(font: HersheyFontId, char: string): Glyph | null {
  const extra = EXTRA_GLYPHS[char];
  if (extra) return extra;
  const raw = FONTS[font].chars[char.charCodeAt(0) - FIRST_CHAR_CODE];
  if (!raw) return null;
  return { strokes: parseHersheyPath(raw.d).map(toStroke), advance: raw.o * 2 };
}
```

```ts
import { normalizeStrokes } from "@/lib/shape/normalize";
import type { Shape, Stroke } from "@/lib/shape/types";
import { glyphFor, type HersheyFontId } from "@/lib/text/hershey";

export const MAX_LINES = 2;
export const MAX_LINE_CHARS = 10;
/** 行距（Hershey 單位）：字高約 21，加上下伸部（g、y）與行間空隙。 */
const LINE_HEIGHT = 32;
const ALLOWED = /^[A-Za-z0-9♥!?&.\- ]$/;

/** 檢查文字；合法回傳 null，不合法回傳給使用者看的訊息。空白也算一個字。 */
export function validateText(text: string): string | null {
  const lines = text.split("\n");
  const bad = [...text.replaceAll("\n", "")].find((c) => !ALLOWED.test(c));
  if (bad) return `不支援的字元「${bad}」：只能用英文字母、數字與 ♥ ! ? & . -`;
  if (text.trim() === "") return "請輸入文字";
  if (lines.length > MAX_LINES) return `最多 ${MAX_LINES} 行`;
  if (lines.some((line) => [...line].length > MAX_LINE_CHARS)) return `每行最多 ${MAX_LINE_CHARS} 個字`;
  return null;
}

/** 排版成來源座標（y 向下）的筆畫：每行置中、每個字的每一筆各自是一個 Stroke，不做連接。 */
export function layoutText(text: string, font: HersheyFontId): Stroke[] {
  return text.split("\n").flatMap((line, row) => {
    const glyphs = [...line].map((c) => glyphFor(font, c)).filter((g) => g !== null);
    const width = glyphs.reduce((sum, g) => sum + g.advance, 0);
    let x = -width / 2;
    return glyphs.flatMap((g) => {
      const dx = x;
      x += g.advance;
      return g.strokes.map((s) => ({
        closed: s.closed,
        points: s.points.map(([px, py]): [number, number] => [px + dx, py + row * LINE_HEIGHT]),
      }));
    });
  });
}

/** 文字 → 正規化的 Shape。呼叫前先用 validateText 檢查。 */
export function textShape(text: string, font: HersheyFontId): Shape {
  return { kind: "text", strokes: normalizeStrokes(layoutText(text, font)) };
}
```

```ts
import type { Point } from "@/lib/shape/types";

/** 點到線段的距離；線段退化成一點時（例如封閉環的首尾）就是點到點的距離。 */
function distanceToSegment(p: Point, a: Point, b: Point): number {
  const dx = b[0] - a[0];
  const dy = b[1] - a[1];
  const lengthSquared = dx * dx + dy * dy;
  const t = lengthSquared === 0 ? 0 : ((p[0] - a[0]) * dx + (p[1] - a[1]) * dy) / lengthSquared;
  const clamped = Math.max(0, Math.min(1, t));
  return Math.hypot(p[0] - (a[0] + clamped * dx), p[1] - (a[1] + clamped * dy));
}

function farthestPoint(points: Point[], start: number, end: number): { index: number; distance: number } {
  let best = { index: -1, distance: -1 };
  for (let i = start + 1; i < end; i++) {
    const distance = distanceToSegment(points[i], points[start], points[end]);
    if (distance > best.distance) best = { index: i, distance };
  }
  return best;
}

/** Douglas-Peucker 折線簡化（非遞迴，避免長輪廓爆堆疊）。首尾兩點一定保留。 */
export function simplifyPolyline(points: Point[], tolerance: number): Point[] {
  if (points.length <= 2) return points;
  const keep = new Uint8Array(points.length);
  keep[0] = 1;
  keep[points.length - 1] = 1;
  const stack: [number, number][] = [[0, points.length - 1]];
  while (stack.length > 0) {
    const [start, end] = stack.pop()!;
    const { index, distance } = farthestPoint(points, start, end);
    if (distance <= tolerance) continue;
    keep[index] = 1;
    stack.push([start, index], [index, end]);
  }
  return points.filter((_, i) => keep[i] === 1);
}

/** 簡化到點數不超過 maxPoints：容許誤差每次加倍。tolerance 必須大於 0。 */
export function simplifyToLimit(points: Point[], tolerance: number, maxPoints: number): Point[] {
  let result = simplifyPolyline(points, tolerance);
  for (let t = tolerance * 2; result.length > maxPoints; t *= 2) {
    result = simplifyPolyline(points, t);
  }
  return result;
}
```

```ts
/** RGBA → 灰階（0 黑、255 白）。透明的部分當成白底。 */
export function toGray(rgba: Uint8ClampedArray): Uint8Array {
  const gray = new Uint8Array(rgba.length / 4);
  for (let i = 0; i < gray.length; i++) {
    const luminance = 0.299 * rgba[i * 4] + 0.587 * rgba[i * 4 + 1] + 0.114 * rgba[i * 4 + 2];
    const alpha = rgba[i * 4 + 3] / 255;
    gray[i] = Math.round(luminance * alpha + 255 * (1 - alpha));
  }
  return gray;
}

/** Otsu 門檻：讓「≤ 門檻」與「> 門檻」兩群的組間變異最大。 */
export function otsuThreshold(gray: Uint8Array): number {
  const histogram = new Array<number>(256).fill(0);
  for (const value of gray) histogram[value]++;
  const total = gray.length;
  const sumAll = histogram.reduce((sum, count, value) => sum + count * value, 0);
  let best = { threshold: 0, variance: -1 };
  let weightBelow = 0;
  let sumBelow = 0;
  for (let t = 0; t < 256; t++) {
    weightBelow += histogram[t];
    sumBelow += t * histogram[t];
    const weightAbove = total - weightBelow;
    if (weightBelow === 0 || weightAbove === 0) continue;
    const meanGap = sumBelow / weightBelow - (sumAll - sumBelow) / weightAbove;
    const variance = weightBelow * weightAbove * meanGap * meanGap;
    if (variance > best.variance) best = { threshold: t, variance };
  }
  return best.threshold;
}

/** 二值化：預設「比門檻暗（≤）」是前景 1；invert 時反過來（亮底深圖之外的情況，例如黑底白圖）。 */
export function binaryMask(gray: Uint8Array, threshold: number, invert: boolean): number[] {
  return Array.from(gray, (value) => ((value <= threshold) !== invert ? 1 : 0));
}
```

```ts
import { contours } from "d3-contour";
import { simplifyToLimit } from "@/lib/geometry/simplify";
import { binaryMask } from "@/lib/image/threshold";
import { MAX_STROKE_POINTS } from "@/lib/limits";
import { normalizeStrokes } from "@/lib/shape/normalize";
import type { Point, Shape } from "@/lib/shape/types";

/** 一個輪廓環（像素座標，y 向下）。points 不重複起點；outer 為 false 代表是洞。 */
export type Ring = { points: Point[]; area: number; outer: boolean };

/** 面積小於影像面積這個比例的環視為雜點，丟掉。 */
const MIN_RING_AREA_RATIO = 0.001;
/** Douglas-Peucker 容許誤差 = 影像對角線 × 這個比例（至少 1 像素）。 */
const SIMPLIFY_RATIO = 0.002;

function polygonArea(points: Point[]): number {
  let twice = 0;
  for (let i = 0; i < points.length; i++) {
    const [x1, y1] = points[i];
    const [x2, y2] = points[(i + 1) % points.length];
    twice += x1 * y2 - x2 * y1;
  }
  return Math.abs(twice) / 2;
}

/** 遮罩（1 = 前景）→ 所有輪廓環。d3-contour 的每個 polygon：第一個環是外框，其餘是洞。環的首尾相同。 */
export function traceRings(mask: number[], width: number, height: number): Ring[] {
  const multiPolygon = contours().size([width, height]).contour(mask, 0.5);
  return multiPolygon.coordinates.flatMap((polygon) =>
    polygon.map((ring, i) => {
      const points = ring as Point[];
      return { points, area: polygonArea(points), outer: i === 0 };
    }),
  );
}

/** 灰階影像 → 可選的輪廓環：二值化、抽輪廓、去雜點、簡化（每環最多 MAX_STROKE_POINTS 點），依面積由大到小排序。 */
export function extractRings(
  gray: Uint8Array,
  width: number,
  height: number,
  threshold: number,
  invert: boolean,
): Ring[] {
  const minArea = width * height * MIN_RING_AREA_RATIO;
  const tolerance = Math.max(1, Math.hypot(width, height) * SIMPLIFY_RATIO);
  return traceRings(binaryMask(gray, threshold, invert), width, height)
    .filter((ring) => ring.area >= minArea)
    .map((ring) => ({
      ...ring,
      // d3 的環首尾相同：簡化時多留一點，再去掉重複的終點
      points: simplifyToLimit(ring.points, tolerance, MAX_STROKE_POINTS + 1).slice(0, -1),
    }))
    .filter((ring) => ring.points.length >= 3)
    .sort((a, b) => b.area - a.area);
}

/** 預設選取：面積最大的外框（rings 已依面積排序，所以是第一個外框）。 */
export function defaultSelection(rings: Ring[]): number[] {
  const index = rings.findIndex((ring) => ring.outer);
  return index < 0 ? [] : [index];
}

/** 選取的環 → 正規化的 Shape，每個環是一個封閉筆畫。 */
export function imageShape(rings: Ring[], selected: number[]): Shape {
  return {
    kind: "image",
    strokes: normalizeStrokes(selected.map((i) => ({ points: rings[i].points, closed: true }))),
  };
}
```

```ts
  errorBodySchema,
  matchResponseSchema,
  statusResponseSchema,
  type MatchRequest,
  type MatchResponse,

/** 給 UI 用的錯誤。status 0 代表連不上；engineDown 為 true 時停用即時吸附並顯示橫幅。 */
export type MatchError = { status: number; message: string; warnings: MatchWarning[]; engineDown: boolean };

export type MatchOutcome = { ok: true; response: MatchResponse } | { ok: false; error: MatchError };

export type FetchLike = (input: string, init?: RequestInit) => Promise<Response>;

const DEFAULT_MESSAGES: Record<number, string> = {
  0: "連不上伺服器",
  400: "圖形不在台灣範圍內（含金門、馬祖）",
  422: "輸入不合法，或所有部件都吸附失敗",
  502: "引擎回應的格式不符合契約",
  503: "引擎暫時無法服務（可能正在更新路網）",
  504: "吸附超過時間上限，請縮小圖形或減少筆畫",
};

/** 狀態碼＋錯誤 body → MatchError。detail 是字串就直接顯示，否則用預設訊息。 */
export function toMatchError(status: number, body: unknown): MatchError {
  const parsed = errorBodySchema.safeParse(body);
  const detail = parsed.success ? parsed.data.detail : undefined;
  return {
    status,
    message: typeof detail === "string" ? detail : (DEFAULT_MESSAGES[status] ?? `吸附失敗（HTTP ${status}）`),
    warnings: parsed.success ? (parsed.data.warnings ?? []) : [],
    engineDown: status === 0 || status === 503,
  };
}

/** POST /api/match。不會丟例外：網路錯誤、HTTP 錯誤、格式不符都變成 { ok: false }。 */
export async function fetchMatch(
  request: MatchRequest,
  signal: AbortSignal,
  fetchImpl: FetchLike = fetch,
): Promise<MatchOutcome> {
  let res: Response;
  try {
    res = await fetchImpl("/api/match", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(request),
      signal,
    });
  } catch {
    return { ok: false, error: toMatchError(0, null) };
  }
  const body: unknown = await res.json().catch(() => null);
  if (!res.ok) return { ok: false, error: toMatchError(res.status, body) };
  const parsed = matchResponseSchema.safeParse(body);
  return parsed.success ? { ok: true, response: parsed.data } : { ok: false, error: toMatchError(502, null) };
}

/** GET /api/status → 目前路網的 build id；引擎連不上或沒有路網時回傳 null。 */
export async function fetchStatus(fetchImpl: FetchLike = fetch): Promise<string | null> {
  try {
    const res = await fetchImpl("/api/status", { cache: "no-store" });
    const parsed = statusResponseSchema.safeParse(await res.json());
    return res.ok && parsed.success ? (parsed.data.data?.build_id ?? null) : null;
  } catch {
    return null;
  }
}
```

```ts
import { z } from "zod";
import { matchRequestSchema } from "@/lib/engine/contract";

/** Route Handler 的外部依賴；測試時換成假的。 */
export type ProxyDeps = {
  engineUrl: string | undefined;
  fetch: (input: string, init: RequestInit) => Promise<Response>;
  timeoutMs: number;
};

/** 引擎自己有 5 秒的吸附上限（spec §5）；這裡多留餘裕，只防引擎完全卡住。 */
export const MATCH_TIMEOUT_MS = 10_000;
export const STATUS_TIMEOUT_MS = 3_000;

export function engineDeps(timeoutMs: number): ProxyDeps {
  return { engineUrl: process.env.ENGINE_URL, fetch, timeoutMs };
}

/** 轉發到引擎，狀態碼與 body 原樣轉回。沒設定 ENGINE_URL 或連不上回 503、逾時回 504。 */
export async function forwardToEngine(
  path: string,
  init: RequestInit & { signal: AbortSignal },
  deps: ProxyDeps,
): Promise<Response> {
  if (!deps.engineUrl) return Response.json({ detail: "伺服器沒有設定 ENGINE_URL" }, { status: 503 });
  const timeout = AbortSignal.timeout(deps.timeoutMs);
  try {
    const res = await deps.fetch(`${deps.engineUrl}${path}`, {
      ...init,
      cache: "no-store",
      signal: AbortSignal.any([init.signal, timeout]),
    });
    return new Response(res.body, {
      status: res.status,
      headers: { "content-type": res.headers.get("content-type") ?? "application/json" },
    });
  } catch {
    return timeout.aborted
      ? Response.json({ detail: "引擎回應逾時" }, { status: 504 })
      : Response.json({ detail: "引擎無法連線" }, { status: 503 });
  }
}

/** POST /api/match：先用 zod 驗證（spec §4.7 的上限），通過才轉給引擎。 */
export async function proxyMatch(request: Request, deps: ProxyDeps): Promise<Response> {
  const body: unknown = await request.json().catch(() => undefined);
  const parsed = matchRequestSchema.safeParse(body);
  if (!parsed.success) {
    return Response.json({ detail: z.prettifyError(parsed.error) }, { status: 422 });
  }
  return forwardToEngine(
    "/match",
    {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(parsed.data),
      signal: request.signal,
    },
    deps,
  );
}

/** GET /api/status → 引擎的 GET /status。 */
export function proxyStatus(request: Request, deps: ProxyDeps): Promise<Response> {
  return forwardToEngine("/status", { method: "GET", signal: request.signal }, deps);
}
```

**排程規則（spec §4.2）：**
- `dragging = true`：第一次立刻送；之後每 300 ms 最多送一次，送的是那段時間內最新的請求。
- `dragging = false`（放開、或一般修改）：取消節流計時器，立刻送。
- 每次送出都先 `abort()` 上一個請求；每個請求有遞增序號，只套用「序號大於已套用序號」的結果，所以就算 `fetch` 不理會 abort，舊結果也不會蓋掉新結果。
- 同一個 request 物件成功送過就不重送（放開時常與最後一次節流送出的是同一個）；最新請求失敗時允許重送（引擎恢復後重試會用到）。
- 取消前端請求不會中斷引擎已經在跑的計算（spec §4.2），所以拖曳中一定要節流。

```ts
    return `有筆畫超過 ${MAX_STROKE_POINTS} 點`;
  }
  return null;
}

export function buildMatchRequest(shape: Shape, t: Transform): MatchRequest {
  return { strokes: transformStrokes(shape.strokes, t) };
```

```ts
import type { MatchOutcome } from "@/lib/engine/client";
import type { MatchRequest } from "@/lib/engine/contract";

/** 拖曳中送出吸附請求的最小間隔（spec §4.2）。 */
export const THROTTLE_MS = 300;

export type SchedulerOptions = {
  send: (request: MatchRequest, signal: AbortSignal) => Promise<MatchOutcome>;
  /** 只會收到「比已套用的更新」的結果，舊結果永遠不會覆蓋新結果。 */
  onOutcome: (outcome: MatchOutcome) => void;
  onPendingChange: (pending: boolean) => void;
  intervalMs?: number;
  now?: () => number;
};

export type MatchScheduler = {
  /**
   * 排程送出 request。dragging 為 true 時節流（每 intervalMs 最多一次，送最新的那個），
   * false 時立刻送出。同一個 request 物件成功送過就不重送；失敗的可以再送。
   */
  schedule: (request: MatchRequest, dragging: boolean) => void;
  /** 取消計時器與進行中的請求，之後不再回呼。 */
  dispose: () => void;
};

export function createMatchScheduler(options: SchedulerOptions): MatchScheduler {
  const { send, onOutcome, onPendingChange, intervalMs = THROTTLE_MS, now = Date.now } = options;
  let latest: MatchRequest | null = null;
  let lastSent: MatchRequest | null = null;
  let lastSentAt = -Infinity;
  let timer: ReturnType<typeof setTimeout> | null = null;
  let controller: AbortController | null = null;
  let issued = 0; // 最後送出的序號
  let applied = 0; // 最後套用的序號

  function clearTimer() {
    if (timer !== null) clearTimeout(timer);
    timer = null;
  }

  function apply(seq: number, outcome: MatchOutcome) {
    applied = seq;
    // 最新的請求失敗了：允許同一個 request 重送（例如引擎恢復後重試）
    if (!outcome.ok && seq === issued) lastSent = null;
    onOutcome(outcome);
    onPendingChange(applied !== issued);
  }

  function fire() {
    clearTimer();
    if (latest === null || latest === lastSent) return;
    const request = latest;
    const seq = ++issued;
    lastSent = request;
    lastSentAt = now();
    controller?.abort();
    const current = new AbortController();
    controller = current;
    onPendingChange(true);
    void send(request, current.signal).then((outcome) => {
      // 被取消的、或比已套用的還舊的結果一律丟掉（序號單調遞增）
      if (current.signal.aborted || seq <= applied) return;
      apply(seq, outcome);
    });
  }

  return {
    schedule(request, dragging) {
      latest = request;
      if (!dragging) return fire();
      if (timer !== null) return;
      const wait = lastSentAt + intervalMs - now();
      if (wait <= 0) return fire();
      timer = setTimeout(fire, wait);
    },
    dispose() {
      clearTimer();
      controller?.abort();
      latest = null;
    },
  };
}
```

```ts
"use client";

import { useEffect, useRef, useState } from "react";
import { fetchMatch, type MatchError } from "@/lib/engine/client";
import type { MatchRequest, MatchResponse } from "@/lib/engine/contract";
import { createMatchScheduler, type MatchScheduler } from "@/lib/match/scheduler";

export type LiveMatch = { response: MatchResponse | null; error: MatchError | null; pending: boolean };

/**
 * 即時吸附：request 變了就排程送出（拖曳中每 300ms 一次、放開立刻送）。
 * enabled 為 false（引擎不可用）時不送。最新的結果是錯誤時清掉舊路線，避免顯示過時的結果。
 */
export function useLiveMatch(
  request: MatchRequest | null,
  dragging: boolean,
  enabled: boolean,
  onEngineDown: () => void,
): LiveMatch {
  const [state, setState] = useState<LiveMatch>({ response: null, error: null, pending: false });
  const schedulerRef = useRef<MatchScheduler | null>(null);
  const onEngineDownRef = useRef(onEngineDown);

  useEffect(() => {
    onEngineDownRef.current = onEngineDown;
  });

  useEffect(() => {
    const scheduler = createMatchScheduler({
      send: (req, signal) => fetchMatch(req, signal),
      onOutcome: (outcome) => {
        if (outcome.ok) {
          setState((s) => ({ ...s, response: outcome.response, error: null }));
          return;
        }
        setState((s) => ({ ...s, response: null, error: outcome.error }));
        if (outcome.error.engineDown) onEngineDownRef.current();
      },
      onPendingChange: (pending) => setState((s) => ({ ...s, pending })),
    });
    schedulerRef.current = scheduler;
    return () => scheduler.dispose();
  }, []);

  useEffect(() => {
    if (request && enabled) schedulerRef.current?.schedule(request, dragging);
  }, [request, dragging, enabled]);

  return state;
}
```

```ts
import { useCallback, useEffect, useState } from "react";
import { fetchStatus } from "@/lib/engine/client";

export type EngineStatus = {
  /** checking：查詢中；ok：可以吸附；down：引擎連不上或沒有路網，停用吸附。 */
  status: "checking" | "ok" | "down";
  /** 目前路網的 build id，例如 20261010T145928Z。 */
  dataVersion: string | null;
};

/** 開頁時查一次 /api/status；retry 重查；吸附遇到 503 或連不上時呼叫 markDown。 */
export function useEngineStatus(): EngineStatus & { retry: () => void; markDown: () => void } {
  const [state, setState] = useState<EngineStatus>({ status: "checking", dataVersion: null });
  const [attempt, setAttempt] = useState(0);

  useEffect(() => {
    let cancelled = false;
    void fetchStatus().then((dataVersion) => {
      if (!cancelled) setState({ status: dataVersion ? "ok" : "down", dataVersion });
    });
    return () => {
      cancelled = true;
    };
  }, [attempt]);

  const retry = useCallback(() => {
    setState((s) => ({ ...s, status: "checking" }));
    setAttempt((n) => n + 1);
  }, []);

  const markDown = useCallback(() => setState((s) => ({ ...s, status: "down" })), []);

  return { ...state, retry, markDown };
}
```

```ts
import type { LonLat } from "@/lib/shape/types";

const XML_ESCAPES: Record<string, string> = { "<": "&lt;", ">": "&gt;", "&": "&amp;", "'": "&apos;", '"': "&quot;" };

function escapeXml(text: string): string {
  return text.replace(/[<>&'"]/g, (c) => XML_ESCAPES[c]);
}

/** 路線 → GPX 1.1（一個 trk、一個 trkseg）。座標取到小數第 6 位（約 0.1 m）。 */
export function buildGpx(points: LonLat[], name: string): string {
  const title = escapeXml(name);
  return [
    '<?xml version="1.0" encoding="UTF-8"?>',
    '<gpx version="1.1" creator="artroute" xmlns="http://www.topografix.com/GPX/1/1">',
    `  <metadata><name>${title}</name></metadata>`,
    "  <trk>",
    `    <name>${title}</name>`,
    "    <trkseg>",
    ...points.map(([lon, lat]) => `      <trkpt lat="${lat.toFixed(6)}" lon="${lon.toFixed(6)}"/>`),
    "    </trkseg>",
    "  </trk>",
    "</gpx>",
    "",
  ].join("\n");
}

/** 下載檔名：英數字以外的字元換成 -，全部去掉就用 route。 */
export function gpxFileName(name: string): string {
  const slug = name
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-+|-+$/g, "");
  return `artroute-${slug || "route"}.gpx`;
}
```

```ts
import type { Transform } from "@/lib/shape/transform";

  transform: z.object({ center: pointSchema, sizeM: z.number().positive(), rotationDeg: z.number() }),
});

type KeyValueStore = Pick<Storage, "getItem" | "setItem">;

/** 瀏覽器的 localStorage。存取 window.localStorage 本身也可能丟錯，所以包在方法裡，由 saveWork／loadWork 的 try 接住。 */
export const browserStore: KeyValueStore = {
  getItem: (key) => window.localStorage.getItem(key),
  setItem: (key, value) => window.localStorage.setItem(key, value),
};

/** 存檔。隱私模式或空間不足時 setItem 會丟錯：放棄這次存檔，不影響使用。 */
export function saveWork(store: KeyValueStore, work: SavedWork): void {
  try {
    store.setItem(STORAGE_KEY, JSON.stringify({ v: 1, ...work }));
  } catch {
    // 不存
  }
}

/** 讀檔。沒有存檔、格式壞掉、版本不符或讀取丟錯都回傳 null。 */
export function loadWork(store: KeyValueStore): SavedWork | null {
  try {
    const parsed = savedWorkSchema.safeParse(JSON.parse(store.getItem(STORAGE_KEY) ?? "null"));
    return parsed.success ? { source: parsed.data.source, transform: parsed.data.transform } : null;
  } catch {
    return null;
  }
}
```

```ts
import type { FeatureCollection, LineString, Point } from "geojson";
import type { MatchResponse, SegmentKind } from "@/lib/engine/contract";

export type SegmentProperties = { kind: SegmentKind };
export type EndpointProperties = { role: "start" | "end" };

export type RouteGeoJson = {
  segments: FeatureCollection<LineString, SegmentProperties>;
  endpoints: FeatureCollection<Point, EndpointProperties>;
};

/** /match 回應 → 地圖圖層資料。沒有回應時回傳空的 FeatureCollection（清掉地圖上的路線）。 */
export function routeGeoJson(response: MatchResponse | null): RouteGeoJson {
  const segments = response?.segments ?? [];
  const points = response?.route.points ?? [];
  const ends: [EndpointProperties["role"], number][] = points.length > 0 ? [["start", 0], ["end", points.length - 1]] : [];
  return {
    segments: {
      type: "FeatureCollection",
      features: segments.map((s) => ({
        type: "Feature",
        properties: { kind: s.kind },
        geometry: { type: "LineString", coordinates: s.points },
      })),
    },
    endpoints: {
      type: "FeatureCollection",
      features: ends.map(([role, i]) => ({
        type: "Feature",
        properties: { role },
        geometry: { type: "Point", coordinates: points[i] },
      })),
    },
  };
}
```

```tsx
"use client";

import type { Map as MapLibreMap } from "maplibre-gl";
import { useEffect, useMemo, useRef, useState, type KeyboardEvent, type PointerEvent } from "react";
import { Button } from "@/components/ui/button";
import { shapeBounds } from "@/lib/shape/normalize";
import {
  dragTransform,
  handlePositions,
  isNudgeKey,
  nudge,
  transformPoint,
  type DragMode,
  type Transform,
} from "@/lib/shape/transform";
import type { LonLat, Shape } from "@/lib/shape/types";

type Props = {
  map: MapLibreMap;
  shape: Shape;
  transform: Transform;
  /** 吸附失敗（warnings）的筆畫索引：目標線畫成紅色。 */
  warned: ReadonlySet<number>;
  /** dragging 為 true 代表還在拖曳（即時吸附會節流），false 代表放開（立刻吸附）。 */
  onChange: (transform: Transform, dragging: boolean) => void;
};

type Drag = { mode: DragMode; start: Transform; from: LonLat; pointerId: number };

const ACCENT = "#7c3aed";
const WARNED = "#dc2626";
const INTERACTIVE = { pointerEvents: "all", touchAction: "none" } as const;

/**
 * 地圖上的編輯器（SVG 疊在地圖上）：目標圖形（虛線）、拖曳本體移動、角落把手等比縮放、旋轉把手旋轉。
 * Pointer Events 讓滑鼠與觸控共用；圖形取得焦點後可以用方向鍵微調。
 */
export function ShapeOverlay({ map, shape, transform, warned, onChange }: Props) {
  const [, setFrame] = useState(0);
  const dragRef = useRef<Drag | null>(null);
  const groupRef = useRef<SVGGElement>(null);
  const bounds = useMemo(() => shapeBounds(shape.strokes), [shape]);

  // 地圖移動或縮放時重畫（座標要重新投影）
  useEffect(() => {
    const rerender = () => setFrame((n) => n + 1);
    const subscriptions = [map.on("move", rerender), map.on("resize", rerender)];
    return () => subscriptions.forEach((s) => s.unsubscribe());
  }, [map]);

  const toScreen = (p: LonLat) => {
    const { x, y } = map.project(p);
    return `${x},${y}`;
  };

  const pointerLonLat = (e: PointerEvent): LonLat => {
    const rect = map.getContainer().getBoundingClientRect();
    const { lng, lat } = map.unproject([e.clientX - rect.left, e.clientY - rect.top]);
    return [lng, lat];
  };

  const begin = (mode: DragMode, e: PointerEvent<SVGElement>) => {
    e.preventDefault();
    e.currentTarget.setPointerCapture(e.pointerId);
    groupRef.current?.focus();
    dragRef.current = { mode, start: transform, from: pointerLonLat(e), pointerId: e.pointerId };
  };

  const track = (dragging: boolean, e: PointerEvent<SVGGElement>) => {
    const drag = dragRef.current;
    if (!drag || drag.pointerId !== e.pointerId) return;
    if (!dragging) dragRef.current = null;
    onChange(dragTransform(drag.mode, drag.start, drag.from, pointerLonLat(e), bounds), dragging);
  };

  const onKeyDown = (e: KeyboardEvent<SVGGElement>) => {
    const next = nudge(transform, e.key, e.shiftKey);
    if (!next) return;
    e.preventDefault();
    onChange(next, true);
  };

  const onKeyUp = (e: KeyboardEvent<SVGGElement>) => {
    if (isNudgeKey(e.key)) onChange(transform, false);
  };

  const recenter = () => {
    const { lng, lat } = map.getCenter();
    onChange({ ...transform, center: [lng, lat] }, false);
  };

  const handles = handlePositions(transform, bounds);
  const topCenter = transformPoint([0, bounds.halfHeight], transform);

  return (
    <>
      <svg className="pointer-events-none absolute inset-0 h-full w-full" aria-label="目標圖形編輯器">
        <g
          ref={groupRef}
          tabIndex={0}
          className="outline-none [&:focus>polygon]:[stroke-width:3]"
          onKeyDown={onKeyDown}
          onKeyUp={onKeyUp}
          onPointerMove={(e) => track(true, e)}
          onPointerUp={(e) => track(false, e)}
          onPointerCancel={(e) => track(false, e)}
        >
          <polygon
            points={handles.corners.map(toScreen).join(" ")}
            fill={ACCENT}
            fillOpacity={0.06}
            stroke={ACCENT}
            strokeOpacity={0.5}
            className="cursor-move"
            style={INTERACTIVE}
            onPointerDown={(e) => begin("move", e)}
          />
          {shape.strokes.map((stroke, i) => (
            <polyline
              key={i}
              data-testid="target-stroke"
              points={(stroke.closed ? [...stroke.points, stroke.points[0]] : stroke.points)
                .map((p) => toScreen(transformPoint(p, transform)))
                .join(" ")}
              fill="none"
              stroke={warned.has(i) ? WARNED : ACCENT}
              strokeWidth={warned.has(i) ? 3 : 2}
              strokeDasharray="6 4"
            />
          ))}
          <polyline
            points={[topCenter, handles.rotate].map(toScreen).join(" ")}
            fill="none"
            stroke={ACCENT}
            strokeWidth={1.5}
          />
          <circle
            cx={map.project(handles.rotate).x}
            cy={map.project(handles.rotate).y}
            r={9}
            fill="white"
            stroke={ACCENT}
            strokeWidth={2}
            className="cursor-grab"
            style={INTERACTIVE}
            aria-label="旋轉"
            onPointerDown={(e) => begin("rotate", e)}
          />
          {handles.corners.map((corner, i) => (
            <rect
              key={i}
              x={map.project(corner).x - 7}
              y={map.project(corner).y - 7}
              width={14}
              height={14}
              fill="white"
              stroke={ACCENT}
              strokeWidth={2}
              className="cursor-nwse-resize"
              style={INTERACTIVE}
              aria-label="縮放"
              onPointerDown={(e) => begin("scale", e)}
            />
          ))}
        </g>
      </svg>
      <Button size="sm" variant="secondary" className="absolute top-3 left-3 shadow" onClick={recenter}>
        圖形移到畫面中央
      </Button>
    </>
  );
}
```

```ts
// 圖片描邊的 Web Worker：解碼、縮圖、灰階、Otsu、抽輪廓都在這裡做，不卡住畫面。
// 解碼後的灰階影像留在 worker 裡，調門檻時不用重新解碼。
import { extractRings, type Ring } from "@/lib/image/rings";
import { otsuThreshold, toGray } from "@/lib/image/threshold";

/** file 有值時重新載入圖片；threshold 為 null 時用 Otsu 自動決定。 */
export type TraceRequest = { id: number; file?: Blob; threshold: number | null; invert: boolean };

export type TraceResponse =
  | { id: number; ok: true; width: number; height: number; threshold: number; rings: Ring[] }
  | { id: number; ok: false; message: string };

/** 描邊用的影像長邊上限（像素）：路線用途不需要更細。 */
const MAX_SIDE = 512;

type GrayImage = { gray: Uint8Array; width: number; height: number };
let image: GrayImage | null = null;

async function decode(file: Blob): Promise<GrayImage> {
  const bitmap = await createImageBitmap(file);
  const scale = Math.min(1, MAX_SIDE / Math.max(bitmap.width, bitmap.height));
  const width = Math.max(1, Math.round(bitmap.width * scale));
  const height = Math.max(1, Math.round(bitmap.height * scale));
  const canvas = new OffscreenCanvas(width, height);
  const ctx = canvas.getContext("2d");
  if (!ctx) throw new Error("瀏覽器不支援 OffscreenCanvas 2D");
  ctx.drawImage(bitmap, 0, 0, width, height);
  bitmap.close();
  return { gray: toGray(ctx.getImageData(0, 0, width, height).data), width, height };
}

async function trace(request: TraceRequest): Promise<TraceResponse> {
  if (request.file) image = await decode(request.file);
  if (!image) throw new Error("還沒有載入圖片");
  const threshold = request.threshold ?? otsuThreshold(image.gray);
  const rings = extractRings(image.gray, image.width, image.height, threshold, request.invert);
  return { id: request.id, ok: true, width: image.width, height: image.height, threshold, rings };
}

self.onmessage = (event: MessageEvent<TraceRequest>) => {
  const { id } = event.data;
  trace(event.data)
    .then((response) => self.postMessage(response))
    .catch((error: unknown) => {
      const message = error instanceof Error ? error.message : "圖片處理失敗";
      self.postMessage({ id, ok: false, message } satisfies TraceResponse);
    });
};
```

```ts
"use client";

import { useCallback, useEffect, useRef, useState } from "react";
import type { TraceRequest, TraceResponse } from "@/lib/image/trace.worker";

type TraceResult = Extract<TraceResponse, { ok: true }>;

/**
 * 圖片描邊 worker 的包裝。只把「最新一次請求」的結果交給 onResult，舊的丟掉。
 * 回傳 trace（送出請求）、working（處理中）、error（最新一次的錯誤訊息）。
 */
export function useImageTrace(onResult: (result: TraceResult) => void) {
  const workerRef = useRef<Worker | null>(null);
  const latestIdRef = useRef(0);
  const onResultRef = useRef(onResult);
  const [working, setWorking] = useState(false);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    onResultRef.current = onResult;
  });

  useEffect(() => {
    const worker = new Worker(new URL("../lib/image/trace.worker.ts", import.meta.url), { type: "module" });
    worker.onmessage = (event: MessageEvent<TraceResponse>) => {
      const response = event.data;
      if (response.id !== latestIdRef.current) return;
      setWorking(false);
      setError(response.ok ? null : response.message);
      if (response.ok) onResultRef.current(response);
    };
    workerRef.current = worker;
    return () => worker.terminate();
  }, []);

  const trace = useCallback((request: Omit<TraceRequest, "id">) => {
    latestIdRef.current += 1;
    setWorking(true);
    workerRef.current?.postMessage({ ...request, id: latestIdRef.current } satisfies TraceRequest);
  }, []);

  return { trace, working, error };
}
```

```tsx
import type { Stroke } from "@/lib/shape/types";

  onStrokes: (strokes: Stroke[]) => void;
};

export function ImageSource({ hasShape, onStrokes }: Props) {
  const [rings, setRings] = useState<Ring[]>([]);
  const [size, setSize] = useState({ width: 0, height: 0 });
  const [selected, setSelected] = useState<number[]>([]);
  const [threshold, setThreshold] = useState(128);

    setRings(result.rings);
    setSize({ width: result.width, height: result.height });
    setThreshold(result.threshold);

    setPreviewUrl(URL.createObjectURL(file));
    trace({ file, threshold: null, invert });
  };

  const toggle = (index: number) => {
    const next = selected.includes(index) ? selected.filter((i) => i !== index) : [...selected, index];
    setSelected(next);
    onStrokes(imageShape(rings, next).strokes);
  };

  return (
    <div className="flex flex-col gap-3">
      <div className="flex flex-col gap-1.5">
        <Label htmlFor="source-image">圖片（PNG、JPG、WebP，最大 5 MB）</Label>

          type="file"
          accept={IMAGE_TYPES.join(",")}
          onChange={(e) => onFile(e.target.files?.[0])}

          <p className="text-xs text-muted-foreground">使用上次儲存的圖形；重新上傳圖片可以調整輪廓。</p>

      </div>

      <div className="flex flex-col gap-2">
        <Label>黑白門檻：{threshold}</Label>
        <Slider
          min={0}
          max={255}
          step={1}
          value={[threshold]}
          disabled={!loaded || working}
          onValueChange={([value]) => setThreshold(value)}
          onValueCommit={([value]) => trace({ threshold: value, invert })}
        />
      </div>

      <div className="flex items-center gap-2">
        <Switch
          id="source-invert"
          checked={invert}
          disabled={!loaded || working}
          onCheckedChange={(checked) => {
            setInvert(checked);
            trace({ threshold, invert: checked });
          }}
        />
        <Label htmlFor="source-invert">反轉（深色背景、淺色圖案）</Label>
      </div>

      {working && <p className="text-sm text-muted-foreground">處理中…</p>}

      {loaded && (
        <div className="flex flex-col gap-1.5">
          <p className="text-xs text-muted-foreground">
            點輪廓加入或移除（藍色＝已選，{selected.length} 個）。預設選最大的外框。
          </p>
          <svg
            viewBox={`0 0 ${size.width} ${size.height}`}
            className="w-full rounded-md border bg-white"
            role="group"
            aria-label="輪廓選取"
          >
            {previewUrl && <image href={previewUrl} width={size.width} height={size.height} opacity={0.35} />}
            {rings.map((ring, i) => (
              <polygon
                key={i}
                points={ring.points.map((p) => p.join(",")).join(" ")}
                fill={selected.includes(i) ? "#2563eb" : "transparent"}
                fillOpacity={selected.includes(i) ? 0.25 : 1}
                stroke={selected.includes(i) ? "#2563eb" : "#64748b"}
                strokeWidth={Math.max(1, size.width / 200)}
                className="cursor-pointer"
                onClick={() => toggle(i)}
              />
            ))}
          </svg>
        </div>
      )}
    </div>
  );
}
```

```tsx
import { useEffect, useMemo, useState } from "react";
import { MapView } from "@/components/map/map-view";
import { ShapeOverlay } from "@/components/map/shape-overlay";
import { ImageSource } from "@/components/source/image-source";
import { TextSource } from "@/components/source/text-source";

import { InfoPanel } from "@/components/studio/info-panel";
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
import { useEngineStatus } from "@/hooks/use-engine-status";
import { useLiveMatch } from "@/hooks/use-live-match";
import { buildMatchRequest, shapeProblem } from "@/lib/match/request";
import { shapeLengthM, type Transform } from "@/lib/shape/transform";
import type { Shape, Stroke } from "@/lib/shape/types";
import { browserStore, loadWork, saveWork, type SavedSource } from "@/lib/storage/work";
import type { HersheyFontId } from "@/lib/text/hershey";
import { textShape, validateText } from "@/lib/text/layout";

type Mode = "text" | "image";
type TextInput = { text: string; font: HersheyFontId };

/** 預設擺在台北 101 附近，長邊 2 km。 */
const DEFAULT_TRANSFORM: Transform = { center: [121.5654, 25.033], sizeM: 2000, rotationDeg: 0 };
const DEFAULT_TEXT: TextInput = { text: "I ♥ TAIPEI", font: "futural" };

export function Studio() {
  // 只在瀏覽器執行（studio-loader 以 ssr: false 載入），所以可以在初始化時讀 localStorage
  const [saved] = useState(() => loadWork(browserStore));
  const [mode, setMode] = useState<Mode>(saved?.source.kind ?? "text");
  const [textInput, setTextInput] = useState<TextInput>(
    saved?.source.kind === "text" ? { text: saved.source.text, font: saved.source.font } : DEFAULT_TEXT,
  );
  const [imageStrokes, setImageStrokes] = useState<Stroke[]>(
    saved?.source.kind === "image" ? saved.source.strokes : [],
  );
  const [transform, setTransform] = useState<Transform>(saved?.transform ?? DEFAULT_TRANSFORM);
  const [dragging, setDragging] = useState(false);
  const engine = useEngineStatus();

  const shape = useMemo<Shape | null>(() => {
    if (mode === "image") return imageStrokes.length > 0 ? { kind: "image", strokes: imageStrokes } : null;
    return validateText(textInput.text) === null ? textShape(textInput.text, textInput.font) : null;
  }, [mode, textInput, imageStrokes]);
  const problem = shape ? shapeProblem(shape) : null;
  const request = useMemo(
    () => (shape && !problem ? buildMatchRequest(shape, transform) : null),
    [shape, problem, transform],
  );
  const match = useLiveMatch(request, dragging, engine.status === "ok", engine.markDown);
  // 圖形不能吸附時（request 為 null）不顯示舊的路線與錯誤
  const response = request ? match.response : null;
  const error = request ? match.error : null;
  const warnings = response?.warnings ?? error?.warnings ?? [];
  const warned = new Set(warnings.map((w) => w.stroke_index));

  useEffect(() => {
    if (dragging) return;
    const source: SavedSource =
      mode === "text" ? { kind: "text", ...textInput } : { kind: "image", strokes: imageStrokes };
    saveWork(browserStore, { source, transform });
  }, [mode, textInput, imageStrokes, transform, dragging]);

  const onTransform = (next: Transform, isDragging: boolean) => {
    setTransform(next);
    setDragging(isDragging);
  };

  return (
    <div className="flex h-dvh flex-col md:flex-row">
      <aside className="order-2 flex max-h-[45dvh] w-full shrink-0 flex-col gap-4 overflow-y-auto border-t p-4 md:order-1 md:max-h-none md:w-96 md:border-t-0 md:border-r">
        <header>
          <h1 className="text-lg font-semibold">artroute</h1>
          <p className="text-sm text-muted-foreground">把文字或圖片放到地圖上，變成合法可騎的自行車路線。</p>
        </header>
        <EngineBanner down={engine.status === "down"} onRetry={engine.retry} />
        <Tabs value={mode} onValueChange={(value) => setMode(value as Mode)}>
          <TabsList className="w-full">
            <TabsTrigger value="text">文字</TabsTrigger>
            <TabsTrigger value="image">圖片</TabsTrigger>
          </TabsList>
          <TabsContent value="text">
            <TextSource
              text={textInput.text}
              font={textInput.font}
              onChange={(text, font) => setTextInput({ text, font })}
            />
          </TabsContent>
          {/* forceMount：切換分頁時保留已上傳的圖片與輪廓 */}
          <TabsContent value="image" forceMount className="data-[state=inactive]:hidden">
            <ImageSource hasShape={imageStrokes.length > 0} onStrokes={setImageStrokes} />
          </TabsContent>
        </Tabs>
        <InfoPanel
          targetLengthM={shape ? shapeLengthM(shape.strokes, transform.sizeM) : null}
          response={response}
          error={error}
          pending={match.pending}
          warnings={warnings}
          problem={problem}
          dataVersion={engine.dataVersion}
          workName={mode === "text" ? textInput.text.replaceAll("\n", " ") : "image"}
        />
      </aside>
      <main className="relative order-1 min-h-0 flex-1 md:order-2">
        <MapView initialCenter={transform.center} response={response}>
          {(map) =>
            shape && (
              <ShapeOverlay map={map} shape={shape} transform={transform} warned={warned} onChange={onTransform} />
            )
          }
        </MapView>
      </main>
    </div>
  );
}
```

**設計說明：**

- 在瀏覽器端攔截：OpenFreeMap 的 style 換成只有背景的空白 style、`/api/status` 回固定的路網版本、`/api/match` 回 `SAMPLE_MATCH_RESPONSE`。所以結果固定、離線也能跑。

```ts
import { readFile } from "node:fs/promises";
import { expect, test } from "@playwright/test";
import { SAMPLE_MATCH_RESPONSE } from "../src/lib/engine/fixtures";

// 不連外：OpenFreeMap 的 style 換成只有背景的空白 style（路線圖層只用 icon，不需要 glyphs）
const BLANK_STYLE = {
  version: 8,
  sources: {},
  layers: [{ id: "background", type: "background", paint: { "background-color": "#f1f5f9" } }],
};

const STATUS = { data: { build_id: "20261010T145928Z", osm_md5: "e2e", created_at: "2026-10-10T15:00:09Z" } };

test("文字 → 放到地圖 → 吸附 → 下載 GPX", async ({ page }) => {
  await page.route("https://tiles.openfreemap.org/**", (route) => route.fulfill({ json: BLANK_STYLE }));
  await page.route("**/api/status", (route) => route.fulfill({ json: STATUS }));
  await page.route("**/api/match", (route) => route.fulfill({ json: SAMPLE_MATCH_RESPONSE }));

  await page.goto("/");
  // 開頁時預設文字也會送一次吸附；這裡等的是「HI」那一次（futural：H 三筆、I 一筆，共 4 筆）
  const hiRequest = page.waitForRequest(
    (r) => r.url().endsWith("/api/match") && r.postDataJSON()?.strokes?.length === 4,
  );
  // 用 role 找：Radix 的分頁面板也以「文字」為名（aria-labelledby），getByLabel 會撞到兩個
  await page.getByRole("textbox", { name: "文字" }).fill("HI");
  const body = (await hiRequest).postDataJSON() as { strokes: { points: [number, number][] }[] };

  // 每一筆各自是一條目標線
  await expect(page.getByTestId("target-stroke")).toHaveCount(4);

  // 吸附結果：路線長度、分數、路網日期、地圖上的段落
  await expect(page.getByText("2.40 km")).toBeVisible();
  await expect(page.getByText("78%")).toBeVisible();
  await expect(page.getByText("2026-10-10")).toBeVisible();
  await expect(page.getByTestId("map")).toHaveAttribute("data-route-segments", "3");
  // warnings 的部件在資訊面板列出
  await expect(page.getByText("第 3 筆：這一筆附近 150 m 內沒有可騎的道路")).toBeVisible();

  // 送出的經緯度在預設位置（台北 101）附近
  const [lon, lat] = body.strokes[0].points[0];
  expect(lon).toBeGreaterThan(121.4);
  expect(lon).toBeLessThan(121.7);
  expect(lat).toBeGreaterThan(24.9);
  expect(lat).toBeLessThan(25.2);

  const downloadPromise = page.waitForEvent("download");
  await page.getByRole("button", { name: "下載 GPX" }).click();
  const download = await downloadPromise;
  expect(download.suggestedFilename()).toBe("artroute-hi.gpx");
  const gpx = await readFile(await download.path(), "utf8");
  expect(gpx).toContain('<trkpt lat="25.030000" lon="121.500000"/>');
  expect(gpx.match(/<trkpt /g)).toHaveLength(SAMPLE_MATCH_RESPONSE.route.points.length);
});
```
